## 📂 Project Folder Structure
- assets
    - Contains all static assets, including:
        1. CSS files
        2. Images
        3. JavaScript files
        4. SCSS files

-sections
    - Contains PHP files for individual website sections.

## 🛠️ SCSS Compiler
- Ensure sass is installed globally on your system.
    - (Install via `npm install -g sass` if not already installed.)
- Navigate to the assets folder.
- Run the following command to compile SCSS files in real-time:
    `npm run sass`

## 🚀 Run Locally
- Open a terminal in the project’s root folder.
- Run the following command to start a local PHP server:
    `php -S 127.0.0.1:8000`
- Open http://127.0.0.1:8000 in your browser to view the website.
